Materi Pembelajaran

7 tab materi — ketuk untuk membuka penjelasan

Visual Studio Code (VS Code) adalah editor kode gratis buatan Microsoft yang paling populer di dunia developer. Ringan, cepat, dan mendukung ribuan ekstensi.

Bagian utama VS Code:

  • Explorer — panel kiri untuk melihat file dan folder proyek.
  • Editor — area tengah tempat menulis kode, dilengkapi pewarnaan sintaks (syntax highlighting).
  • Terminal — panel bawah untuk menjalankan perintah (buka dengan Ctrl + `).
  • Activity Bar — ikon navigasi di paling kiri (Explorer, Search, Source Control, Extensions).
  • Status Bar — baris bawah menampilkan info file, encoding, dan baris kursor.

Ekstensi wajib untuk pemula:

  • Live Server — preview halaman HTML secara live di browser.
  • Prettier — merapikan format kode otomatis.
  • HTML CSS Support — autocomplete untuk tag dan atribut HTML.
  • Emmet — sudah built-in, menulis kode HTML lebih cepat dengan singkatan.
shortcut // Shortcut penting di VS Code Ctrl + N → File baru Ctrl + S → Simpan file Ctrl + P → Cari file cepat Ctrl + Shift + P → Command Palette Ctrl + ` → Buka Terminal Ctrl + / → Komentar baris Alt + ↑/↓ → Pindah baris kode

HTML (HyperText Markup Language) adalah bahasa markup untuk membuat struktur halaman web. Ditulis menggunakan tag — diawali <tag> dan ditutup </tag>.

Struktur dasar dokumen HTML:

struktur.html <!DOCTYPE html> <html> <head> <title>Judul Halaman</title> </head> <body> <h1>Hello World</h1> </body> </html>

Tag-tag penting:

  • <html> — elemen akar seluruh halaman.
  • <head> — info halaman (judul, meta, stylesheet).
  • <body> — isi yang tampil di browser.
  • <h1> s.d. <h6> — heading, dari terbesar ke terkecil.
  • <p> — paragraf teks.
  • <a href="..."> — membuat link.
  • <img src="..."> — menampilkan gambar.
  • <b> — teks tebal, <i> — teks miring.
  • <hr> — garis pemisah horizontal.
  • <br> — pindah baris (line break).
contoh.html <h1>Nama Saya</h1> <p>Hobi saya <b>membaca</b></p> <p>Ini <i>miring</i></p> <hr>

📋 List (Daftar)

HTML menyediakan dua jenis list utama:

  • Unordered List — daftar dengan bullet (titik). Menggunakan tag <ul> dan tiap item <li>.
  • Ordered List — daftar bernomor. Menggunakan tag <ol> dan tiap item <li>.
list.html <ul> <li>HTML</li> <li>CSS</li> </ul> <ol> <li>Langkah pertama</li> <li>Langkah kedua</li> </ol>

📊 Tabel

Tabel dibuat dengan <table>, baris <tr>, header <th>, dan sel data <td>.

tabel.html <table> <tr> <th>Nama</th> <th>Kelas</th> </tr> <tr> <td>Budi</td> <td>X IPA 1</td> </tr> </table>
TagFungsi
<ul>List bullet (tidak berurut)
<ol>List bernomor (berurut)
<li>Item dalam list
<table>Membuat tabel
<tr>Baris tabel (table row)
<th>Header kolom tabel
<td>Sel data tabel

Atribut adalah informasi tambahan yang ditulis di dalam tag pembuka. Format: nama="nilai".

Atribut yang wajib diketahui:

AtributFungsiContoh
hrefAlamat tujuan link<a href="...">
srcSumber gambar/file<img src="...">
altTeks alternatif gambar<img alt="...">
titleTooltip saat hover<a title="...">
idIdentitas unik elemen<div id="...">
classGrup elemen untuk styling<p class="...">
targetBuka link di tab baru<a target="_blank">
styleInline CSS<p style="color:red">

Contoh penggunaan lengkap:

atribut.html <a href="https://google.com" target="_blank"> Buka Google </a> <img src="foto.jpg" alt="Foto Profil" width="100"> <div id="header" class="container"> <p style="color: cyan;">Teks berwarna</p> </div>

Perbedaan id dan class:

  • id harus unik — hanya boleh satu elemen dengan id tertentu per halaman.
  • class bisa dipakai berulang di banyak elemen.

🔗 Link (Hyperlink)

Link dibuat dengan tag <a> (anchor) dan atribut href. Ada dua jenis link:

  • Link eksternal — menuju ke situs lain (contoh: google.com).
  • Link internal — menuju halaman lain di situs yang sama (contoh: tentang.html).
link.html <!-- Link eksternal, buka tab baru --> <a href="https://google.com" target="_blank">Google</a> <!-- Link ke halaman lain --> <a href="tentang.html">Tentang Kami</a> <!-- Link ke email --> <a href="mailto:guru@sekolah.id">Email Guru</a>

🖼️ Gambar

Gambar ditampilkan dengan tag <img>. Ini adalah self-closing tag — tidak punya tag penutup.

gambar.html <img src="logo.png" alt="Logo Sekolah"> <img src="foto.jpg" alt="Foto Kegiatan" width="300" height="200">
AtributFungsi
srcPath/lokasi file gambar (wajib)
altTeks pengganti jika gambar gagal dimuat
widthLebar gambar (piksel)
heightTinggi gambar (piksel)

💡 Tips: atribut alt penting untuk aksesibilitas (screen reader) dan SEO.

Semantic HTML adalah penggunaan tag yang maknanya jelas — tidak hanya <div> dan <span> untuk segalanya. Tag semantik membantu browser, mesin pencari, dan screen reader memahami struktur halaman.

Tag semantik modern:

TagFungsi
<header>Bagian kepala halaman/section
<nav>Navigasi (menu)
<main>Konten utama halaman
<section>Bagian tematik konten
<article>Konten mandiri (artikel, berita)
<aside>Konten sampingan (sidebar)
<footer>Bagian kaki halaman

Contoh struktur semantik:

semantic.html <header> <h1>Website Saya</h1> <nav> <a href="#">Home</a> <a href="#">About</a> </nav> </header> <main> <article> <h2>Artikel Terbaru</h2> <p>Isi artikel...</p> </article> </main> <footer> <p>&copy; 2025 Website Saya</p> </footer>

✅ Keuntungan semantic HTML: aksesibilitas lebih baik, SEO lebih ramah, dan kode lebih mudah dibaca.

Form digunakan untuk mengumpulkan input dari pengguna — seperti login, pendaftaran, atau kuesioner.

Struktur form dasar:

form.html <form> <label>Nama:</label> <input type="text" name="nama"> <label>Email:</label> <input type="email" name="email"> <button type="submit">Kirim</button> </form>

Jenis input yang umum:

typeFungsi
textInput teks satu baris
emailInput email (validasi otomatis)
passwordInput password (tersembunyi)
numberInput angka
checkboxKotak centang (bisa banyak)
radioPilihan tunggal
submitTombol kirim form

Elemen form lain:

  • <textarea> — input teks multi-baris.
  • <select> dan <option> — dropdown pilihan.
  • <label> — label untuk input (terhubung lewat for).

💡 Tips: selalu pasangkan <label> dengan <input> agar mudah diakses dan form lebih ramah pengguna.
